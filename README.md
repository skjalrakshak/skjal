# SK Jalrakshak Innovations

SK Jalrakshak Innovations Private Limited — smart water intelligence systems, edge telemetry, cloud dashboards, and predictive analytics for industrial and environmental monitoring. 

## Tech Stack
- HTML5
- Tailwind CSS
- GSAP & ScrollTrigger (Cinematic Animations)
- Lenis (Smooth Scrolling)
- Node.js (Local Server)

## Local Development
1. Start the local server:
   ```bash
   node server.js
   ```
   Or use python:
   ```bash
   python -m http.server 8080
   ```
2. Navigate to `http://localhost:8080` (or `3000` if using server.js).

## Design Architecture
The site is built with a "Liquid Glass" dark-theme cinematic aesthetic, prioritizing high performance animations and premium typography.
